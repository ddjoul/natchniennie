пра.бел — небольшое обновление поверх layout-5

это не полный сайт: архив содержит новый styles.css, HTML и profile-layout.js.
скопируйте их поверх предыдущей версии. оставьте прежние app.js, config.js и папку images со своими логотипом, курсором и кнопками. база не меняется.

изменения
• кнопки меню выровнены по правому краю первой кнопки; первая остаётся по центру панели.
• сортировка справа.
• второстепенный текст: Tektur 14 / 400. мелкий: 12 / 400. заголовки карточек: 24 / 600.
• подпись под логотипом: 14 / 400, ранее выбранный line-height 10 сохранён (это плотнее высоты шрифта).
• имя автора остаётся крупным заголовком; фото 255×255, текст справа. цитата без линии, отступа слева, чёрного выделения или курсива: серый 14 / 400.
• соцсети сохранены под фото, чтобы не уменьшать ширину биографии.
• profile-layout.js оформляет первую строку bio как краткую информацию 24 / 400 только если после неё есть перенос строки. остальной текст 14 / 400. пример:
г. Віцебск, БДУ, 21 год
текст биографии...
поле quote можно использовать для обычного текста цитаты; оно оформляется тем же серым шрифтом.
• надписи кнопок — часть PNG из прошлой версии. вес/размер текста внутри изображения CSS не меняет. для изменения самих букв требуется новый экспорт изображений кнопок. чёрно-белые изображения оставлены без изменений.
• поиска, языка, комментариев, Supabase, ссылок и логики app.js обновление не касается.

сначала сделайте резервную копию. после GitHub Pages обновите страницу. проверьте фото/цитату и сортировку на телефоне. 404.html при глубоком URL по-прежнему требует base href с путём вашего репозитория.
